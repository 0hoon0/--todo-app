# 대시보드 기능

## 왜 만드나요? (배경)
지금은 할 일 목록만 볼 수 있어서, "오늘 얼마나 끝냈는지", "전체적으로 얼마나 남았는지"를 한눈에 알기 어렵습니다. 목록을 하나하나 세어보지 않아도 되도록, 숫자로 요약해서 보여주는 화면(대시보드)이 필요합니다.

## 무엇을 만드나요? (요구사항)
- 화면 위쪽에 탭 두 개를 만든다: **목록**(지금 화면) / **대시보드**(새 화면).
- 대시보드에는 다음 숫자를 보여준다.
  - 전체 할 일 개수
  - 완료한 개수
  - 남은 개수
  - 완료율(%) — 예: "3 / 5 완료 (60%)"
- 완료율은 막대(progress bar)로도 시각적으로 보여준다.
- 오늘 만든 할 일 개수도 보여준다 (`createdAt`이 오늘 날짜인 것만 센다).
- **범위 밖(이번에 안 만듦)**: 주간/월간 그래프, 날짜별 이력 관리, 서버 저장 — 지금은 로컬 데이터로만 통계를 낸다.

## 어떻게 만드나요? (설계)
- 상태(할 일 데이터)는 지금처럼 `src/hooks/useTodos.ts`가 그대로 관리한다. 대시보드는 이 훅이 주는 `todos` 배열을 읽기만 하고, 새로운 저장 로직은 만들지 않는다.
- 새 파일:
  - `src/components/Dashboard.tsx` — `todos`를 받아서 통계 숫자와 막대를 계산·표시하는 컴포넌트. 통계 계산(전체/완료/남음/완료율/오늘 개수)은 이 파일 안의 작은 순수 함수로 만들어서, 나중에 테스트하기 쉽게 한다.
  - `src/App.css`에 대시보드용 스타일을 추가한다 (새 CSS 파일은 만들지 않는다).
- `src/App.tsx` 수정:
  - 현재 보고 있는 화면이 "목록"인지 "대시보드"인지 저장하는 간단한 상태 하나(`view`)를 추가한다.
  - 위쪽에 탭 버튼 두 개를 추가해서 `view`를 바꾼다.
  - `view`가 "대시보드"면 기존 목록 대신 `<Dashboard todos={todos} />`를 보여준다.
- 재사용: 기존 `useTodos()` 훅과 `Todo` 타입(`src/types.ts`)을 그대로 사용한다. 새로운 localStorage 키나 별도 저장 방식은 만들지 않는다.

## 예외 상황
- 할 일이 하나도 없을 때: 완료율은 "0%"로 표시하고(0으로 나누기 방지), "아직 할 일이 없어요" 같은 안내 문구를 보여준다.
- 모든 할 일을 완료했을 때: 완료율 100%와 막대가 꽉 찬 상태로 보여준다.

## 확인 방법
- `npm run dev`로 실행 후, 할 일을 추가/완료 처리하면서 대시보드 탭의 숫자와 막대가 바로바로 바뀌는지 눈으로 확인한다.
- 할 일이 0개인 상태에서 대시보드를 열어 에러 없이 "0%"와 안내 문구가 뜨는지 확인한다.
- `npm run build`로 타입 에러 없이 빌드되는지 확인한다.
